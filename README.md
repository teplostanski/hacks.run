# hacks.run

Developer tools at [hacks.run](https://hacks.run). Built with vinext, TypeScript and Vite+.

Requires Node.js 22.18+ and pnpm 12+

```sh
pnpm install --frozen-lockfile
pnpm dev
```

```sh
pnpm check
pnpm lint:fix
pnpm format
pnpm build
pnpm preview
```

Background adapted from [forges](https://github.com/danielroe/forges) (MIT).
